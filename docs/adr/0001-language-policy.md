# 0001. Language policy

- Status: Accepted
- Date: 2026-11-04

## Context
The owner is German-speaking. The project is meant to be public and a portfolio piece; AI agents work on it across many sessions.

## Decision
Everything permanent is American English: code, comments, commits, PRs, README, AGENTS.md, docs. User-visible strings are English source text with a German translation. Temporary plans in `docs/plans/` may be German and are deleted once implemented. Chat with the owner is German.

## Consequences
Consistent repository, readable for anyone. Agents must translate decisions from German conversations into English docs.

## Alternatives considered
German docs: rejected, limits portfolio value and mixes languages in code.
